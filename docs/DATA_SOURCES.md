
Each card contains:

-  ID 
-  Unicode symbol 
-  display name 
-  category 

The symbols are ordinary Unicode characters and are not retrieved from an external image service.

## Technical references

Implementation decisions are based on official browser/tooling documentation:

-  MDN Web Storage API 
-  MDN localStorage 
-  MDN Web Audio API 
-  MDN `prefers-reduced-motion` 
-  Vite documentation 
-  Vitest documentation 
-  ESLint documentation 

Gameplay does not depend on an external API or remote dataset.
