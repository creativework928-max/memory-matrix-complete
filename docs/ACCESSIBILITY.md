# Accessibility

Memory Matrix provides:

- semantic HTML
- keyboard activation
- visible keyboard focus
- accessible button names
- grid semantics for the card board
- live game status
- non-color status indicators
- large touch targets
- reduced-motion support
- higher contrast support

## Keyboard

- Tab: move through controls
- Enter / Space: activate focused card/control
- P: pause/resume
- R: restart
- M: toggle sound
- Escape: close dialogs
